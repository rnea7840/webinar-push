1. Source prospects

            
Runs all four feeds (search + followers + groups + posts). Caps each feed at the size below.

            
            
          


          

            
2. Personalize (Anthropic)

            
Generates connect note + DM + InMail + email per prospect, scores 0–10, routes channel.

            
            
          


          

            
3. Queue drafts

            
Promotes drafted prospects to "queued" so the sender picks them up. No-op in sandbox mode.

            
          


          

            
4. Send now

            
Drains the queue. Distributes across accounts, respects per-channel caps. Live mode only.

            
            
          

        


        

          The tick cron runs every 30 min automatically: personalize → queue → send → due follow-ups → poll inbox replies. Manual buttons above are for first-run / on-demand bursts.
